# installed-software-inventory

Скрипт для Windows, который собирает полный список установленного ПО: обычные программы, portable, Microsoft Store, Steam/Epic/GOG, Scoop, WSL и SDK. На выходе — интерактивный HTML-отчёт с поиском и фильтрами, CSV, Markdown и JSON.

Главное отличие от «просто перечислить реестр»: скрипт обходит диски целиком, группирует все `.exe` по папкам и проверяет каждую папку — существует ли, сколько весит, сколько файлов. Пустые и почти пустые папки, апдейтеры, кэши, junction-дубли и дампы установщиков отбрасываются и попадают в `reports/excluded.csv` с причиной. Ничего не теряется молча.

## Требования

- Windows 10/11
- PowerShell 5.1 (встроенный) или PowerShell 7
- Права пользователя достаточно; часть путей может быть недоступна без админа

## Быстрый старт

```powershell
git clone https://github.com/hydroimperium/installed-software-inventory.git
cd installed-software-inventory
.\Get-InstalledSoftware.ps1 -Open
```

Или двойным кликом: `run.cmd`.

Если PowerShell блокирует запуск:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Get-InstalledSoftware.ps1
```

Полный прогон на машине с двумя SSD (~2200 exe, 100+ тыс. папок) занимает около двух минут. Во время обхода показывается прогресс.

## История и изменения

Скрипт запоминает результат в `reports/history.json`. При следующем запуске он сравнивает списки и показывает:

- **новые** программы — появились с прошлого запуска;
- **обновлённые** — сменилась версия или размер;
- **пропавшие** — были и исчезли.

В HTML это бейджи «новое» / «обновлено», галочка **«только изменения»** и счётчики в шапке. В `changes.csv` — плоский список изменений. Чтобы начать с чистого листа, удали `history.json`.

## Параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `-OutputDir` | `.\reports` | Куда писать отчёты |
| `-MinGameSizeMB` | `100` | Минимальный размер папки игры |
| `-MinPortableSizeMB` | `3` | Минимальный размер portable-программы |
| `-IncludeSystem` | выкл. | Показать служебное ПО сразу, без фильтра |
| `-NoStore` | — | Не собирать Microsoft Store |
| `-NoGames` | — | Не собирать игры |
| `-NoPortable` | — | Не обходить диски (только реестр, Store, Steam/Epic/GOG, Scoop, WSL) |
| `-ExtraRoots` | — | Дополнительные папки для поиска |
| `-OverridesPath` | `.\overrides.psd1` | Файл ручных правок |
| `-SkipShortcuts` | — | Не разбирать ярлыки «Пуск» и рабочего стола |
| `-Audit` | — | Показать папки с exe, которые не попали в отчёт |
| `-Open` | — | Открыть HTML после сборки |

Примеры:

```powershell
# без обхода дисков, быстро
.\Get-InstalledSoftware.ps1 -NoPortable

# добавить свой диск с софтом
.\Get-InstalledSoftware.ps1 -ExtraRoots 'E:\portable','F:\tools'

# проверить полноту и открыть отчёт
.\Get-InstalledSoftware.ps1 -Audit -Open
```

## Откуда берутся данные

1. **Реестр** — `HKLM`/`HKCU`, 32- и 64-битные ветки `Uninstall`, плюс `App Paths` для восстановления путей.
2. **Microsoft Store** — `Get-AppxPackage`, человеческие имена из `AppxManifest`.
3. **Steam** — все библиотеки из `libraryfolders.vdf`, манифесты и папки без манифеста.
4. **Epic Games** — манифесты лаунчера.
5. **GOG** — ветка реестра `GOG.com\Games`.
6. **Scoop** — `%USERPROFILE%\scoop\apps`.
7. **WSL** — установленные дистрибутивы.
8. **SDK/тулчейны** — Android SDK, Edge WebView2, Scoop.
9. **Диски** — полный обход всех фиксированных дисков: все `.exe`, сгруппированные по папкам. Обход идёт через `DirectoryInfo`, без чтения файлов, с отсечением `Windows`, `WinSxS`, `$Recycle.Bin`, `Temp`, `node_modules`, `.git`, `WindowsApps`, junction-ов и кэшей сборки.
10. **Ярлыки** — «Пуск» и рабочий стол, как страховка от нестандартных мест установки.

## Как отбираются программы

Каждая папка с `.exe` проверяется по цепочке:

1. **Контейнер?** корень диска, `Program Files`, `AppData`, рабочий стол — пропускаем, но смотрим их подпапки.
2. **Служебное?** апдейтеры, кэши, `bin/lib/resources`, компоненты Edge/Office/AMD/Epic/WSL — в `excluded.csv`.
3. **Уже найдено?** совпадение по пути или имени с реестром, Store, Steam — дубль отбрасывается.
4. **Дамп установщиков?** нет DLL и главный exe — `setup/install` — отбрасывается.
5. **Игра?** путь `torrent/Games/steamapps`, `UnityPlayer.dll`, `Engine`, `*-Win64-Shipping.exe` — порог `MinGameSizeMB`.
6. **Иначе portable** — порог `MinPortableSizeMB`.

Дополнительно: размеры считаются один раз за проход (сумма по дереву), nested-папки сворачиваются в верхнюю, `bin/bin64` поднимается к папке приложения.

## Фильтры в HTML

- поиск по названию, издателю и пути;
- чипы по категориям: Приложение, Инструмент, Игра, Store, Системное;
- галочка **«скрыть служебное»** — убирает Visual C++, .NET, SDK, драйверы и прочие рантаймы (включена по умолчанию);
- галочка **«скрыть Microsoft и компоненты»** — убирает Windows/Microsoft-компоненты и всё служебное, но оставляет то, что вы реально запускали;
- галочка **«только изменения»** — оставляет новые и обновлённые программы;
- галочка **«нет записи о запуске»** — оставляет программы, которые ни разу не запускались через проводник; поле «Запуск» — дата последнего запуска по журналу UserAssist;
- копии одной программы (две установки Happ, Roblox и т.п.) сворачиваются в одну строку с меткой `+1`, полный список путей — в подсказке;
- клик по пути открывает папку в проводнике;
- сортировка по любому столбцу.

## Ручные правки

Если путь не определяется (например, установка без записи `InstallLocation`), создай `overrides.psd1` рядом со скриптом:

```powershell
@{
    Names = @{
        'Python 3.11.9' = @{ Path = 'C:\Users\me\AppData\Local\Programs\Python\Python311' }
        'Старое имя'    = @{ Name = 'Новое имя'; Category = 'Инструмент' }
    }
    Extra = @(
        @{ Name = 'Мой тул'; Path = 'D:\tools\mytool'; Version = '1.0' }
    )
}
```

Файл в `.gitignore` — личные пути не попадут в репозиторий. Шаблон: `overrides.example.psd1`.

## Выходные файлы

| Файл | Что внутри |
|---|---|
| `software-inventory.html` | Интерактивная таблица с фильтрами |
| `software-inventory.csv` | Для Excel (UTF-8) |
| `software-inventory.md` | Текстовая версия по категориям |
| `software-inventory.json` | Для скриптов |
| `excluded.csv` | Все папки с exe, которые не попали в отчёт, с причиной |
| `changes.csv` | Новые, обновлённые и пропавшие программы (со второго запуска) |
| `history.json` | Снимок прошлого запуска для сравнения |
| `audit.txt` | То же, компактно (при `-Audit`) |

## Ограничения

- Portable-программа без `.exe` в своей папке (лаунчер в другом месте) может не попасть в список.
- Дата запуска берётся из журнала проводника (UserAssist): программы из автозагрузки и консольные утилиты могут не иметь записи, даже если вы ими пользуетесь.
- Инсталляторы и архивы на диске не считаются установленными программами — они в `excluded.csv`.
- Программы, установленные только для другого пользователя, не видны.
- Размер папки считается рекурсивно и может занимать время на больших каталогах.
- Служебные компоненты Windows (VC++, .NET, UI.Xaml) в отчёт попадают, но скрыты фильтром — это сделано намеренно.
