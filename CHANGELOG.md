# История версий

## 1.0.0 — 2026-11-16

Первый стабильный релиз.

**Сбор данных**
- Реестр (HKLM/HKCU, 32/64), App Paths, Microsoft Store с человеческими именами, Steam (все библиотеки), Epic, GOG, Scoop, WSL, Android SDK, Edge WebView2.
- Полный обход дисков: все `.exe`, группировка по папкам, размеры одним проходом.
- Отсев апдейтеров, кэшей, junction-ов, дампов установщиков и папок-загрузок; всё отброшенное — в `excluded.csv` с причиной.

**Проверки качества**
- Игры: порог по размеру и числу файлов.
- Portable: порог по размеру.
- Мёртвые пути реестра не попадают в отчёт.
- Аудит покрытия: каждая папка с exe либо в отчёте, либо в `excluded.csv`.

**Отчёт**
- HTML с поиском, категориями, карточками-сводкой, сортировкой, ссылками на папки, бейджами «новое/обновлено», фильтрами «скрыть служебное», «скрыть Microsoft», «нет записи о запуске», «только изменения».
- CSV (инвариантные числа), Markdown, JSON, `changes.csv`, `history.json`, `excluded.csv`, `audit.txt`.

**Инфраструктура**
- Чистые функции вынесены в `lib/Core.ps1`.
- 37 юнит-тестов без внешних зависимостей + смоук-прогон.
- CI на GitHub Actions: синтаксис, тесты, смоук.
- Коды выхода: `0` — успех, `1` — фатальная ошибка, `2` — ошибки источников при `-Strict`.
